# Connect CruSam to Claude Desktop

About a minute, once.

## You need

- **CruSam**, installed and opened at least once.
- **Claude Desktop**, installed and signed in (get it from claude.ai/download).

## Connect

1. Open **CruSam**. It asks **"Use CruSam with Claude"**. Click **Connect**.
   (If you clicked *Not now*: go to **Profile → Claude Desktop → Connect**.)
2. Click **Restart Claude**. Claude closes and opens again with CruSam.
3. Start a **new chat** in Claude and try: *"Using CruSam, give me an overview."*

That's it. CruSam updates keep the connection up to date by themselves.

## Using it

- Keep **CruSam open** (it can be minimized) and ask Claude in plain words:
  *"Create an invoice from this photo"*, *"Change Ramesh's basic to 16000"*,
  *"Make the final bill for May and email it to the client"*.
- CruSam pops up as a small window on the right and shows what Claude is
  doing. The **Follow Claude** button (eye) at the top turns this on or off;
  the button next to it switches between the small and the full window.
- Claude always shows a preview and asks before it saves an invoice, deletes
  anything or sends an email.
- Before its first change in each chat, a backup of your data is saved.

## If something goes wrong

| What you see | What to do |
|---|---|
| Claude doesn't mention CruSam | Quit Claude from the tray icon (right-click → Quit), open it again, start a new chat. |
| Profile says "Claude Desktop not found" | Install Claude Desktop, open it once and sign in, then click Connect. |
| "The database is busy" | CruSam was saving at that moment. Ask Claude to try again. |
| Anything else | Send Soham a screenshot of CruSam's Profile → Claude Desktop card. |
